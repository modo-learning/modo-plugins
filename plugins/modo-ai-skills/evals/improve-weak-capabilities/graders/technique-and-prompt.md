Rubric ground truth for the step up. Delegation: level 1 hands over a whole job vaguely with no scope, role or output and does not look at it; level 2 hands over a whole task with a minimal brief, no review point and no decision kept; level 3 gives a clear task with scope and output format and keeps some decisions ("give me three options, I'll choose"); level 4 splits work on purpose, gives a role, inputs, constraints and what done looks like, and sets a review step before Claude carries on. Strategic Thinking: level 1 explicitly leaves the choice of approach to Claude; level 2 mentions the purpose or audience in passing; level 3 connects the task to a goal beyond the chat and uses it to prioritise; level 4 weighs options and trade-offs and uses Claude to test the plan (alternatives, counter-arguments, risks). Workflow Design: level 1 treats each request as stand-alone and re-explains context; level 2 moves through steps ad hoc with no plan stated and repeats setup; level 3 lays out steps in order and feeds earlier outputs into later steps; level 4 defines a repeatable process with a fixed format or rules, a template, stages with a check between them.

PASS if EACH of the two improved capabilities has BOTH (a) a concrete technique that moves the user toward the next level or above in the rubric's terms (for Delegation, things like stating a role, inputs, constraints, what done looks like, or a review step before Claude carries on; for Workflow Design, things like a fixed format or rules, a template, stages with a check between them), and (b) a "try this next time" prompt the user could copy and paste as it stands (a full sentence or short block of text addressed to Claude, not a description of a prompt), preferably worded for this user's pricing deck work.
A prompt may contain a slot for the user's own data (such as "[paste rows]") and still be copy-ready. It is not copy-ready if the whole prompt is a placeholder or only describes a prompt.
FAIL if either capability lacks the technique or the copy-ready prompt, if the technique is generic advice with no link to the next level (such as "be clearer"), or if a prompt is only a placeholder like "[your prompt here]".
