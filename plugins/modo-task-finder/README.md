# Modo Task Finder

Modo Task Finder looks through your recent Claude chats, finds the tasks you
keep coming back to, and suggests one practical fix for each: a reusable
skill, a scheduled task, or a connector to add first. You run it with
`/my-tasks`, optionally with a time window such as `3 months`.

**Status: early development.** The command currently loads and confirms the
window you asked for. The analysis itself is still being built, and this
README will describe exactly what the plugin reads and how your data is
handled before the first release.
